## 🔧 **必需的Android配置**

### **1. 权限配置 (android/app/src/main/AndroidManifest.xml)**

需要添加以下权限：

```xml
<!-- 摄像头权限 -->
<uses-permission android:name="android.permission.CAMERA" />

<!-- 麦克风权限 -->
<uses-permission android:name="android.permission.RECORD_AUDIO" />

<!-- 网络权限 (WebRTC需要) -->
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />

<!-- 蓝牙权限 (原有功能) -->
<uses-permission android:name="android.permission.BLUETOOTH" />
<uses-permission android:name="android.permission.BLUETOOTH_ADMIN" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />

<!-- Android 12+ 蓝牙权限 -->
<uses-permission android:name="android.permission.BLUETOOTH_SCAN" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />

<!-- 摄像头特性声明 -->
<uses-feature android:name="android.hardware.camera" android:required="false" />
<uses-feature android:name="android.hardware.camera.autofocus" android:required="false" />
```

### **2. ProGuard配置 (android/app/proguard-rules.pro)**

```proguard
# React Native WebRTC
-keep class org.webrtc.** { *; }
-dontwarn org.webrtc.**

# React Native Vision Camera
-keep class com.mrousavy.camera.** { *; }
-dontwarn com.mrousavy.camera.**

# React Native Permissions
-keep class com.zoontek.rnpermissions.** { *; }
-dontwarn com.zoontek.rnpermissions.**
```

## ⚠️ **常见兼容性问题和解决方案**

### **问题1: Gradle版本不兼容**
**症状**: `Unsupported Gradle version`
**解决方案**: 
```gradle
// android/gradle/wrapper/gradle-wrapper.properties
distributionUrl=https\://services.gradle.org/distributions/gradle-8.3-all.zip
```

### **问题2: Java版本不兼容**
**症状**: `Unsupported Java version`
**解决方案**: 确保使用Java 17
```gradle
// android/app/build.gradle
compileOptions {
    sourceCompatibility JavaVersion.VERSION_17
    targetCompatibility JavaVersion.VERSION_17
}
```

### **问题3: NDK版本问题**
**症状**: NDK相关错误
**解决方案**: 
```gradle
// android/build.gradle
ndkVersion = "25.1.8937393"
```

### **问题4: 权限运行时错误**
**症状**: 应用崩溃或权限被拒绝
**解决方案**: 确保在AndroidManifest.xml中声明所有必需权限
