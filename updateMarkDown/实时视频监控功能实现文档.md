# 实时视频监控功能实现文档

## 📋 功能概述

在React Native蓝牙打印机管理应用中成功集成了实时视频监控功能，通过WebRTC技术实现移动端摄像头画面的实时传输到Web端观看。

## 🏗️ 系统架构

```
┌─────────────────┐    WebRTC     ┌─────────────────┐    Socket.IO    ┌─────────────────┐
│   React Native │ ◄──────────── │   NestJS Server │ ──────────────► │   Web Viewer    │
│   (推流端)       │               │   (信令服务器)    │                 │   (观看端)       │
└─────────────────┘               └─────────────────┘                 └─────────────────┘
        │                                   │                                   │
        │                                   │                                   │
   ┌────▼────┐                         ┌────▼────┐                         ┌────▼────┐
   │ Camera  │                         │ WebRTC  │                         │ Video   │
   │ Stream  │                         │ Gateway │                         │ Player  │
   └─────────┘                         └─────────┘                         └─────────┘
```

## 🔄 工作流程

### 直播开始流程

1. **权限检查**: 用户点击"开始直播" → 检查摄像头和麦克风权限
2. **WebRTC初始化**: 创建PeerConnection → 获取本地媒体流
3. **房间创建**: 生成唯一房间ID → 加入Socket.IO房间
4. **信令交换**: 等待观看者连接 → 交换offer/answer
5. **流传输**: 建立P2P连接 → 开始视频流传输

### 观看流程

1. **连接服务器**: Web端输入房间ID → 连接Socket.IO服务器
2. **加入房间**: 发送join-room信令 → 服务器确认加入
3. **接收Offer**: 收到推流端的offer → 创建answer响应
4. **建立连接**: ICE候选交换 → P2P连接建立
5. **视频播放**: 接收远程流 → 在video元素中播放

## 🚀 部署说明

### 依赖安装

**React Native端**:
```bash
npm install react-native-vision-camera react-native-webrtc react-native-permissions socket.io-client
```

**后端**:
```bash
npm install @nestjs/websockets @nestjs/platform-socket.io socket.io
```

### 配置要求

1. **iOS配置**: 在Info.plist中添加摄像头和麦克风权限描述
2. **Android配置**: 在AndroidManifest.xml中添加相应权限
3. **服务器配置**: 确保防火墙开放WebSocket端口

### 启动步骤

1. **启动后端服务器**:
   ```bash
   cd server
   npm run start:dev
   ```

2. **启动React Native应用**:
   ```bash
   npm start
   ```

3. **访问Web端观看器**:
   ```
   http://localhost:3000/viewer.html
   ```
