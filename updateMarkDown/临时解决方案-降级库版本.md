# 临时解决方案：降级库版本以避免兼容性问题

## 🎯 **策略说明**

由于网络问题和Kotlin版本兼容性复杂，我们采用降级策略：
- 保持 Kotlin 1.8.0（避免网络下载问题）
- 降级部分库版本以确保兼容性
- 优先保证核心功能可用

## 📦 **建议的库版本调整**

### **方案一：最小化实时监控功能**

暂时移除复杂的库，先让基础应用构建成功：

```bash
# 临时移除有问题的库
npm uninstall react-native-vision-camera react-native-webrtc

# 保留基础权限库（版本较稳定）
npm install react-native-permissions@3.8.0
```

### **方案二：使用兼容版本**

如果需要保留实时监控功能，使用较旧但稳定的版本：

```bash
# 降级到兼容版本
npm install react-native-vision-camera@3.9.0
npm install react-native-webrtc@118.0.7
npm install react-native-permissions@3.8.0
```

```gradle
android {
    compileOptions {

```

## 🚀 **执行步骤**

### **步骤1：选择方案**

**方案一（推荐）- 先让基础应用工作**：
```bash
# 移除有问题的库
npm uninstall react-native-vision-camera react-native-webrtc

# 清理并重新安装
rm -rf node_modules
npm install

# 重新构建
npx react-native run-android
```

**方案二 - 保留功能但降级版本**：
```bash
# 降级库版本
npm install react-native-vision-camera@3.9.0 react-native-webrtc@118.0.7

# 清理并重新构建
rm -rf node_modules
npm install
npx react-native run-android
```

### **步骤2：验证基础功能**

确保以下功能正常：
- ✅ 应用启动
- ✅ 蓝牙功能
- ✅ 导航功能
- ✅ 基础UI

### **步骤3：逐步添加功能**

基础应用工作后，可以逐步添加功能：

1. **先添加权限管理**：
   ```bash
   npm install react-native-permissions@3.8.0
   ```

2. **再添加摄像头功能**：
   ```bash
   npm install react-native-vision-camera@3.9.0
   ```

3. **最后添加WebRTC**：
   ```bash
   npm install react-native-webrtc@118.0.7
   ```

## 🔍 **问题排查**

### **如果仍有构建问题**

1. **检查网络连接**：
   ```bash
   ping repo.maven.apache.org
   ```

2. **使用国内镜像**（在 android/build.gradle 中）：
   ```gradle
   allprojects {
       repositories {
           maven { url 'https://maven.aliyun.com/repository/google' }
           maven { url 'https://maven.aliyun.com/repository/central' }
           google()
           mavenCentral()
       }
   }
   ```

3. **清理所有缓存**：
   ```bash
   # 清理 Gradle 缓存
   cd android
   .\gradlew clean
   .\gradlew --stop
   rm -rf .gradle
   
   # 清理 React Native 缓存
   cd ..
   npx react-native start --reset-cache
   
   # 清理 npm 缓存
   npm cache clean --force
   ```
